# Skill: Knox-Keene Analysis
ID: analyze-violations

This skill enables the agent to analyze L.A. Care Member Handbooks, Provider Directories, and other administrative documents for violations of the Knox-Keene Act, specifically HSC 1368.01 (Expedited Grievances).

## Usage
- Provide a document link or text snippet.
- The agent will check for required 72-hour expedited grievance notices and contact information.
- It will flag missing or misleading information as a violation.
