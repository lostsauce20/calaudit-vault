[ SECURITY PROTOCOLS & SPECIFICATIONS ]

LOCAL AUDIO PROCESSING

After the user-initiated model download, this utility decodes, resamples, and transcribes the selected audio in the browser. The application code does not send the selected audio or transcript to a transcription API.

PRIVACY-CONSCIOUS BY DESIGN

Local processing reduces reliance on a remote transcription API, but it does not secure the device, browser extensions, clipboard, files, or surrounding workflow. This tool is not a HIPAA certification or legal-compliance guarantee; review organizational requirements before using regulated recordings.

[ STEP-BY-STEP PRIVACY MANUAL ]

  1. Stage 1 // Drag & Drop Audio: Drag an audio file (.mp3, .wav, or .m4a) and drop it inside the dashed zone, or click to browse.
  2. Stage 2 // Model Download: After you click Initialize, the browser downloads the selected model and helper libraries. Browser caching may reduce future downloads, but availability varies by browser and cache state.
  3. Stage 3 // Web Audio Resampling: The browser's local Web Audio API decodes the audio and resamples the buffer to mono 16kHz to prepare it for neural network processing.
  4. Stage 4 // Neural Inference: Transformers.js runs the Whisper model locally with the browser-supported execution backend.
  5. Stage 5 // Extract Text: The completed transcript appears on the page for you to review and copy.

[ THE COST OF CLOUD DICTATION SOFTWARE ]

Cloud transcription services generally send audio to provider infrastructure for processing, while this tool performs inference in the browser after downloading its model. Enterprise services may also provide live dictation, support, integrations, and compliance controls that this utility does not.

The CalAudit Free Audio-to-Text Transcriber is a free, file-based utility with no account requirement. Once the selected model and helper libraries are available, transcription runs locally. It is not a replacement for the workflow, support, or compliance capabilities of an enterprise dictation product.

[ FREQUENTLY ASKED QUESTIONS ]

▶ Where is my recording processed?
The application decodes and transcribes the selected file in the browser. Initializing the engine downloads the model and helper libraries, and local processing does not protect against a compromised device, browser extension, or unsafe file handling.
▶ Which model does this tool use?
It uses the English-only Xenova Whisper Tiny and Whisper Base ONNX models for browser-side execution. Tiny uses fewer resources, while Base may provide better accuracy.
▶ How does this compare to Dragon Legal Anywhere?
This is a free, file-based browser transcriber rather than a live enterprise dictation service. It requires a model download and does not include Dragon's workflow, support, or compliance features.
▶ Can I use this for real-time dictation as an alternative to Dragon?
No. This tool processes prerecorded audio files; it does not provide live microphone dictation.
▶ Why use a browser-based local model instead of a cloud subscription?
A local model avoids sending the recording to a transcription API. The tradeoffs are a sizable model download, device resource use, browser compatibility, and fewer workflow features.
▶ What affects transcription performance?
Performance depends on the selected model, recording length, browser, device resources, and the backend selected by the Transformers.js runtime. Supported acceleration may improve inference speed.
