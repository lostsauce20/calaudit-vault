Free Browser-Based Privacy & Utility Tools

Free tools for PDFs, images, text, links, audio, security, and Android

// OPERATIONAL MANIFESTO: DECENTRALIZED DATA sovereignty

Many routine tasks can be completed directly in a modern browser without uploading the selected content to an application server. This collection provides focused utilities for images, text, links, PDFs, audio files, and Android workflows.

Processing varies by tool. Most operations run in the page after its assets load. The audio transcriber downloads model weights and helper libraries only after you initialize it. Review each tool's notice and inspect sensitive outputs before relying on them.

Frequently Asked Questions

Are these tools actually free to use?

Yes. Every tool in this hub is free, with no account, subscription, or usage caps. The code is open-source under the GNU AGPLv3, so you're also free to inspect, modify, or self-host it.

Do any of these tools upload my files to a server?

The tools are designed to process selected content in the browser rather than upload it to a CalAudit processing API. Page assets still come from the website, and the audio transcriber downloads model files and helper libraries after you initialize it.

What does "100% offline" or "client-side" actually mean?

Client-side means the tool's main processing logic executes in your browser. Most tools can continue after their assets load; the audio transcriber requires a first-use model and library download before local transcription is available.

Do I need to create an account or provide personal information?

No account, email address, or sign-up is required to use the tools in this hub.

Is my data stored anywhere after I close the tab?

The tools do not intentionally upload your selected content to a CalAudit processing API. Browser caches, downloads, clipboard history, extensions, or device-level logging may still retain data, so use an appropriate device profile for sensitive work.

Are the tools open source? Can I audit the code myself?

Yes. All original utility code and web application logic on this platform are distributed under the GNU AGPLv3, so you're free to read, modify, redistribute, or fold it into your own projects under those terms, while public health forms and guides are licensed under CC BY-NC 4.0.

Which tool should I use to remove GPS and camera data from a photo?

Use the Free Photo Metadata & EXIF Remover. It re-encodes JPEG and PNG images to reduce standard embedded metadata exposure and reports before-and-after SHA-256 file hashes.

Can I use these tools on my phone, or only on desktop?

The tools use modern browser APIs and responsive layouts, but support and memory limits vary by browser, device, file size, and feature. Test the specific tool and output on your device before relying on it.
