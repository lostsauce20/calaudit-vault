EDITORIAL STUDY

File Signatures, Magic Bytes & Fake Extensions Explained

What are magic bytes and file signatures?

Filename extensions such as .png or .pdf are labels. Many formats also begin with recognizable byte patterns commonly called magic bytes or file signatures.

Comparing the label with a recognized header can reveal an obvious mismatch. Headers can be forged, signatures can overlap, and this tool reads only a small prefix, so the result does not establish chain of custody, authenticity, integrity, or safety.

Which file signatures can this checker recognize?

Some common signature prefixes include:

  • • PNG Image: 89 50 4E 47
  • • JPEG/JPG Image: FF D8 FF
  • • PDF Document: 25 50 44 46
  • • Windows Executable (EXE): 4D 5A
  • • WebP Image: 52 49 46 46 (with WebP offsets)

How can a file signature reveal a renamed or spoofed extension?

Adversaries exploit operating system defaults (like "Hide file extensions for known file types") to mask dangerous scripts and malware payloads. An attacker can name a malicious executable tax-form.pdf.exe.

When known extensions are hidden, a name ending in .pdf.exe may be misleading. If this tool recognizes an executable header while the visible extension claims .pdf, it reports a mismatch for further investigation.

[ SCOPE AND LIMITATIONS ]

The application code reads a small file prefix locally and does not submit the selected file to a CalAudit upload endpoint. It recognizes only the signatures listed on this page and reports all other headers as inconclusive.

A header comparison is not antivirus analysis. Do not open a suspicious file based on a green result, and use appropriate malware scanning, provenance checks, and organizational controls for untrusted files.

[ SYSTEM_FAQ: MAGIC_BYTE_AUDITING_PRINCIPLES ]

▶ What are magic bytes and file signatures?
Magic bytes are recognizable byte patterns that many file formats place near the beginning of a file. Comparing a known signature with the filename extension can reveal an obvious mismatch, but it does not prove the file is authentic or safe.
▶ How do I check a file's real type or header?
Select a file and the browser reads a short prefix from it. The tool compares that prefix with its limited local signature list and reports a consistent, mismatched, or inconclusive result.
▶ Can this detect a renamed or spoofed file extension?
It can flag some obvious mismatches. For example, a recognized PDF signature paired with a .png filename can be reported for further investigation. Headers can also be forged, so the result is only a structural clue.
▶ Which file formats can this magic byte checker recognize?
The current local list recognizes common PNG, JPEG, PDF, ZIP and ZIP-based Office containers, EXE, GIF, WebP, WAV, and AVI header patterns. Other formats are reported as inconclusive.
▶ Is this a malware scanner?
No. The checker only compares a small file-header prefix with a limited signature database. A matching header does not establish that a file is trustworthy, authentic, or free of malware.
