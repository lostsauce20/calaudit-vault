EDITORIAL STUDY

Zero-Width Unicode Hidden Text Explained

How do zero-width Unicode characters hide text?

The tool encodes the payload as UTF-8 bytes, converts those bytes to bits, then maps zero bits to a Zero-Width Space (&#8203;) and one bits to a Zero-Width Non-Joiner (&#8204;).

These symbols normally have zero horizontal width. Many copy-and-paste paths preserve them, but normalization, sanitization, messaging apps, editors, and content-management systems may remove or alter them.

Will zero-width hidden text survive copy and paste?

The application code performs encoding and decoding locally and does not submit entered text to a CalAudit endpoint. The payload is not confidential: anyone who knows the encoding scheme can extract it, and device or browser risks still apply.

[ LIMITATIONS OF ZERO-WIDTH PAYLOADS ]

Zero-width characters are ordinary Unicode code points, not a durable rights-management system. A recipient can inspect, remove, replace, or accidentally normalize them, and different copies can carry the same identifier.

Use the feature for reversible labeling or experimentation, not to protect a secret or prove a legal claim. Test the exact destination path before relying on payload survival.

FORENSIC FAQ

Common Questions

▶ What is zero-width text?
Zero-width text uses Unicode characters that normally occupy no visible horizontal space. This tool maps a UTF-8 payload into zero-width characters and embeds it inside visible cover text.
▶ How do I hide text inside normal text with zero-width characters?
Enter visible cover text and the payload you want to encode, then generate the output. The hidden payload is inserted as zero-width Unicode characters and can be extracted later if those characters are preserved.
▶ Can I extract or decode zero-width hidden text?
Yes. Paste text produced by this tool into the extractor. If the expected boundary markers and zero-width payload survived, the browser decodes the hidden UTF-8 text locally.
▶ Will invisible zero-width text survive copy and paste?
Sometimes. Messaging apps, editors, content-management systems, normalization, and sanitization may strip or alter zero-width characters, so test the exact destination before relying on the payload.
▶ Is zero-width hidden text encryption?
No. The encoding is reversible obfuscation, not encryption. Anyone who knows the encoding scheme can inspect or remove the hidden characters, so do not use it to protect a secret.
