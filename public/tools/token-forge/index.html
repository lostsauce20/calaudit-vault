[ SECURE RANDOM TOKEN GENERATION & SECRET-HANDLING NOTES ]

The generator uses crypto.getRandomValues() and rejection sampling rather than Math.random(). The displayed entropy estimate assumes each character is independently selected from the active character pool.

The page does not submit generated values to a CalAudit endpoint or store them in localStorage or cookies. Browser extensions, a compromised device, screenshots, and clipboard history can still expose a secret. Treat copied tokens as sensitive and rotate any value that may have been disclosed.

[ SYSTEM_FAQ: ANTI_HARVESTING_CRYPTO_PRINCIPLES ]

▶ How do I generate a secure random token?
Choose a length from 8 to 128 characters, select one or more character sets, and click the generate button. The tool uses crypto.getRandomValues() with rejection sampling to select characters locally.
▶ Can I use this as a random password generator?
Yes, it can generate password-style random strings from uppercase letters, lowercase letters, numbers, and symbols. Check the password rules of the service where you plan to use the result.
▶ Can this generate an API token or secret key?
It can generate a random secret value for systems that allow user-created tokens, but it does not create or register an API credential with any provider. Follow the target system's required format and length.
▶ How secure is crypto.getRandomValues()?
crypto.getRandomValues() is the browser's cryptographically secure random-number API. This tool also uses rejection sampling to avoid modulo bias when mapping random values into the selected character pool.
▶ Are generated tokens saved or uploaded?
The page does not submit generated values to a CalAudit endpoint or store them in localStorage or cookies. Clipboard history, browser extensions, screenshots, or a compromised device can still expose a copied secret.
